<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `.env.local` → processo Node.js | Credenciais Twilio nunca expostas ao browser; variáveis sem `NEXT_PUBLIC_` prefix são server-only |
| migration SQL → banco Supabase | Migration executada via CLI autenticado; RLS habilitado imediatamente após CREATE TABLE |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Information Disclosure | `.env.local` com credenciais Twilio | mitigate | Arquivo já está em `.gitignore`; nunca commitar valores reais |
| T-05-02 | Tampering | `whatsapp_message_log` sem RLS | mitigate | `ENABLE ROW LEVEL SECURITY` imediatamente após CREATE TABLE na migration; política tenant_whatsapp_log_all via JWT app_metadata |
| T-05-03 | Elevation of Privilege | pg_cron script comentado com vault secrets | accept | Bloco comentado — não executa automaticamente; vault secrets configurados manualmente pelo operador |
| T-05-SC | Tampering | npm install twilio | mitigate | Package legitimacy audit em 05-RESEARCH.md confirma pacote oficial Twilio Inc. publicado no GitHub (twilio/twilio-node); revisar manualmente se `npm view twilio` retornar publisher diferente de "twilio" |
</threat_model>
