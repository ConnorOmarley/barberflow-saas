LÓGICA DE CÁLCULO (fazer dentro do componente antes do return):
Montar um Map de `clientId → { fullName, whatsappNumber, activeStamps }`:

```
1. Montar um Map<clientId, lastRedemptionIso> a partir de redemptions
   (para cada clientId, guardar o ISO string de MAX created_at)

2. Para cada stamp em stamps:
   a. Obter lastRedemption do Map (ou '1970-01-01T00:00:00Z' se ausente)
   b. Se stamp.created_at > lastRedemption → incrementar contador activeStamps deste client
   c. Guardar { fullName: stamp.clients?.full_name, whatsappNumber: stamp.clients?.whatsapp_number }

3. Converter o Map em array clientProgress, ordenado por activeStamps DESC
   (cartelas completas primeiro)
```

  {/* Banner quando programa está inativo */}
  {loyaltyRule && !loyaltyRule.is_active && (

    </Alert>
  )}

  {/* Estado vazio */}
  {clientProgress.length === 0 ? (
    <div className="flex flex-col items-center justify-center py-20 gap-4">
      <p className="text-[0.9375rem] font-semibold text-foreground">

        return (
          <div
            key={client.clientId}
            className={`rounded-lg border p-4 ${isFull ? 'border-amber-600/50 bg-amber-950/20' : 'border-white/[0.06] bg-white/[0.02]'}`}

                {client.whatsappNumber && (

                )}

              </span>
            </div>

            {/* Barra de progresso */}
            <div className="mt-3 h-2 w-full rounded-full bg-white/10">
              <div

              />
            </div>

            {/* Botão Resgatar — apenas quando cartela completa */}
            {isFull && (

                disabled={isRedeemingThis}
                className="mt-3 w-full bg-amber-600 text-black hover:bg-amber-500 font-semibold"
              >
                {isRedeemingThis && redeemingId === client.clientId ? (

                  `Resgatar — ${loyaltyRule?.reward_description ?? 'recompensa'}`
                )}
              </Button>
            )}
          </div>
        )
      })}
    </div>
  )}

  <LoyaltyConfigSheet

    onOpenChange={setConfigOpen}
    rule={loyaltyRule}
    onSaved={() => setConfigOpen(false)}
  />
