    - deactivateService(serviceId) → getClaims → UPDATE services SET is_active = false WHERE id = ? AND barbershop_id = JWT → revalidatePath → { success } | { error }
    - syncServiceBarbers(serviceId, barberIds: string[]) → for each barberId in barberIds: upsert barber_services (barber_id, service_id) — but use DELETE+INSERT pattern: DELETE barber_services WHERE service_id = serviceId AND barber_id NOT IN barberIds, then INSERT missing entries. Create src/app/actions/services.ts:
  'use server' at top
  Import createClient from '@/lib/supabase/server', revalidatePath from 'next/cache'
  Export createService, updateService, deactivateService — exact same pattern as barbers.ts (getClaims → barbershop_id from JWT → DB operation → revalidatePath → return { data | success | error })
  For createService: do NOT accept barbershop_id as parameter — always from getClaims

Add to src/app/actions/barber-services.ts (do not rewrite the file — append the new export):
  Export async function syncServiceBarbers(serviceId: string, barberIds: string[])
    - getClaims → validate barbershop_id
    - DELETE FROM barber_services WHERE service_id = serviceId AND barber_id NOT IN (barberIds) — if barberIds is empty, DELETE all WHERE service_id = serviceId
    - INSERT INTO barber_services (barber_id, service_id) for each barberId not already in the table — use ON CONFLICT DO NOTHING
    - revalidatePath('/dashboard/servicos')
    - Return { success: true } | { error }

Note: syncServiceBarbers leaves commission_type and commission_value as NULL when adding from the service side (per D-15 — commission is set from barber edit drawer only).
