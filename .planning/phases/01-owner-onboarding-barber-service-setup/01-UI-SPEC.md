## Spacing Scale

Inherited from Phase 0. All values are multiples of 4.

| Token | Value | Usage in Phase 1 |
|-------|-------|-----------------|
| xs | 4px | Icon-to-text gaps, inline badge padding, step connector dots |
| sm | 8px | Between form label and input, between stacked inputs, tag gaps |
| md | 16px | Card/panel internal padding, form field gaps, drawer section padding |
| lg | 24px | Wizard step padding, panel section gap, drawer header padding |
| xl | 32px | Wizard container vertical margin, drawer max-content width inner margin |
| 2xl | 48px | Onboarding card vertical centering offset |
| 3xl | 64px | Not used in Phase 1 |

Exceptions:
- Wizard step indicator dots: 8px diameter, 4px gap between dots
- Barber card avatar: 48px × 48px
- Service list row height: minimum 56px (touch target compliance)
- Drawer width: `w-[480px]` on desktop, `w-full` on mobile (below lg breakpoint)
- Confirm dialog: `max-w-[420px]`
- Touch targets: minimum 44px height on all interactive elements (buttons, rows, select triggers)

## Typography

Inherited from Phase 0. Base: 16px = 1rem. Font weights: **400 (regular) and 600 (semibold) only.**

| Role | Size | Weight | Line Height | Usage in Phase 1 |
|------|------|--------|-------------|-----------------|
| Body | 14px (0.875rem) | 400 (regular) | 1.5 | Drawer field helper text, list secondary info, form error messages |
| Label | 14px (0.875rem) | 400 (regular) | 1.4 | Form field labels, list column headers |
| Subheading | 15px (0.9375rem) | 600 (semibold) | 1.3 | Panel/section titles (matches existing `PanelHeader`), step titles in wizard |
| Heading | 20px (1.25rem) | 600 (semibold) | 1.2 | Wizard step heading, drawer title |
| KPI value | 34px (2.125rem) | 800 (extrabold) | 1.05 | KPI numbers only — existing `KpiRow` pattern, no new instances in Phase 1 |

Note: The 34px/extrabold slot is carried from Phase 0 KPI pattern. Phase 1 does not add new KPI cards but must not break the existing row.

Tabular numerals (`tabular-nums`) on: time slots, price values, duration values.

| Text primary | `#f3f4f6` | `--foreground` | All primary text |
| Text secondary | `#94a3b8` | `--text-secondary` | Barber subtitle, service details, form helper text |
| Text tertiary | `#64748b` | `--text-tertiary` | Timestamps, inactive labels, step connector |
| Border hairline | `rgba(255,255,255,0.07)` | `--hairline` | Card borders, drawer borders, list row separators |

**Accent `#d4a574` reserved for:**
1. Primary CTA buttons (wizard "Próximo", drawer "Salvar", "Confirmar agendamento")
2. Focus ring on active form inputs (`--ring`)
3. Setup checklist widget progress indicator (border + icon)
4. Active sidebar nav item icon glow (existing pattern — do not change)
5. Wizard step indicator (active step dot)
6. "Convidar barbeiro" secondary CTA in equipe card
7. Hover state on "Ver agenda completa" and similar secondary text links

Accent is NOT used for: regular borders, inactive state backgrounds, icon colors on non-CTA elements, text in data tables.

**Status color mapping** (appointment status pills):
- `CONFIRMED` → gold pill: `color: #d4a574; background: rgba(212,165,116,0.12)` → class `.badge-scheduled`
- `COMPLETED` → emerald pill: `color: #34d399; background: rgba(16,185,129,0.12)` → class `.badge-done`
- `CHECKED_IN` → violet pill: `color: #a78bfa; background: rgba(139,92,246,0.14)` → class `.badge-progress`
- `PENDING` → slate pill: `color: #94a3b8; background: rgba(148,163,184,0.1)` → new `.badge-pending`
- `CANCELLED` → muted: `color: #64748b; background: rgba(100,116,139,0.1)` → new `.badge-cancelled`

### 1. /onboarding — 4-Step Wizard

```
Viewport: full height, background #0b0f17
Layout: flex column, items center, justify center, min-h-screen, py-12

  └── Wizard container: max-w-[560px] w-full mx-4
        └── Brand mark (above card): identical to auth pages — "B" logo + "BARBERFLOW" text
            gap-3, mb-8
        └── Step indicator: flex row, gap-2, mb-6, justify center
              4 dots: h-2 w-2 rounded-full
              Active: bg-[#d4a574], w-4 (wider pill)
              Completed: bg-[#d4a574]/40
              Upcoming: bg-white/15
        └── Wizard card: surface-card auth-card, p-8 (32px)
              └── Step label: text-xs font-semibold tracking-[0.12em] uppercase
                             text-[#d4a574], mb-2
                             e.g. "PASSO 2 DE 4"
              └── Step heading: Heading/20px/semibold, text-foreground, mb-1
              └── Step body: Body/14px/regular, text-secondary, mb-6
              └── Form fields: gap-4 between groups
              └── Navigation row: flex justify-between, mt-6, gap-3
                    └── "Voltar" button: variant=ghost, h-11 — hidden on step 1
                    └── "Próximo" / "Concluir" button: variant=default (gold), h-11, flex-1 max-w-[200px] ml-auto
```

Wizard step progression bar: fixed at top of wizard card, h-1, full width.
- Background: `rgba(255,255,255,0.08)`
- Filled portion: `background: linear-gradient(90deg, #e8c89a, #d4a574)`
- Width: `(currentStep / totalSteps) * 100%`, transition duration 300ms ease

Resume behavior: on load, wizard detects last completed step via DB query and auto-scrolls to the first incomplete step. No visual "welcome back" message — just silently resumes. The step indicator shows progress accumulated so far.

### Step 1: Nome + Timezone

Fields:
- "Nome da barbearia" — Input, required, placeholder "Ex: Barbearia do João"
- "Fuso horário" — Select, required, default "America/Sao_Paulo"
  - Options limited to Brazilian timezones: America/Sao_Paulo, America/Manaus, America/Belem, America/Fortaleza, America/Recife, America/Maceio, America/Bahia, America/Cuiaba, America/Porto_Velho, America/Boa_Vista, America/Rio_Branco, America/Noronha

### Step 2: Horários da Barbearia

Layout: 7-row grid (one row per weekday). Each row:
- Day label (text-sm font-medium, w-16): "Dom", "Seg", "Ter", "Qua", "Qui", "Sex", "Sáb"
- Toggle switch (shadcn `switch` component): "Aberto" / "Fechado"
- When open: two time inputs side by side — "Início" and "Fim" (text-sm, w-24 each, type=time)
- When closed: row is muted, time inputs hidden

Default: Seg–Sex open, 09:00–18:00. Dom–Sáb closed. User adjusts.

New component needed: `switch` (add to install command if not already in Phase 0).

### Step 3: Primeiro Barbeiro

Fields:
- "Nome do barbeiro" — Input, required, placeholder "Ex: Carlos Silva"
- "Telefone (opcional)" — Input, type=tel, placeholder "(11) 99999-9999"
- "Foto (opcional)" — file input, accept="image/*" — shows circular preview (48px) when file selected. Label: "Foto do barbeiro"
- "Enviar convite por email (opcional)" — Checkbox + conditional Input for email when checked
  - Checkbox label: "Convidar por email para acessar o painel"
  - Email input appears when checked: placeholder "email@barbeiro.com"

### Step 4: Primeiro Serviço

Fields:
- Quick-fill templates row (above form): 3 buttons styled as outlined pill chips
  - "Corte (30min, R$40)", "Barba (20min, R$25)", "Corte + Barba (50min, R$60)"
  - Clicking pre-fills the form fields below; form remains editable
  - Chip style: border border-white/15, rounded-full, px-3 py-1.5, text-xs font-medium
  - text-[var(--text-secondary)], hover:border-[#d4a574]/40 hover:text-[#d4a574]
- "Nome do serviço" — Input, required, placeholder "Ex: Corte degradê"
- "Duração" — Select, required, options: 15, 20, 25, 30, 40, 45, 50, 60, 75, 90 (minutes). Display format: "30 min"
- "Preço" — Input, type=number, min=0, step=0.01, required, prefix label "R$"
- CTA: "Concluir configuração" (gold, full width, h-11)

## Interaction Contract

### Form Behavior (inherits Phase 0, extended)

- Validation: React Hook Form + Zod, triggered on submit
- Field error: displayed below input, Body/14px in `--destructive`, 4px top gap
- Required field indicator: asterisk (*) appended to label text in `--text-tertiary` color
- Submit button: disabled + Loader2 `animate-spin` while awaiting server action
- All mutations use Server Actions (`'use server'`), not API routes

### Drawer Behavior

- Opening animation: slide in from right, duration 300ms, `ease-out`
- Closing: slide out right, duration 200ms
- Backdrop: `bg-black/50` — clicking backdrop closes drawer (Sheet default behavior)
- Scroll: body scroll locked when drawer is open (Sheet handles this)
- Mobile: drawer becomes full-width bottom sheet at < lg breakpoint

### Combobox (Client Search)

- Typing debounce: 300ms before querying Supabase for client matches
- Search matches on: name (ilike) OR whatsapp_number (ilike)
- Minimum 2 characters to trigger search
- Loading state: Loader2 spinner inside combobox input during query
- Maximum displayed results: 8 entries (scroll within command list)

### Optimistic Updates

- Marking appointment COMPLETED: update row status badge immediately, revert on error
- Cancelling appointment: remove row from active list immediately (or grey out), revert on error

### Status Transitions

Phase 1 manual transitions (owner or barber can trigger):
- `CONFIRMED → COMPLETED` (barber via "Concluir" in DropdownMenu)
- `CONFIRMED → CANCELLED` (owner via "Cancelar" in DropdownMenu + confirm dialog)
- `PENDING → CONFIRMED` — NOT exposed in Phase 1 UI (auto-confirmed on manual creation per D-16)
Phase 1 creates appointments with status = `CONFIRMED` directly.

## Accessibility Contract

Inherits all Phase 0 accessibility requirements, extended:

- All form inputs have associated `<Label>` with `htmlFor` matching input `id`
- Drawer: `aria-label="Novo agendamento"` on Sheet component, focus trapped within while open
- Dialog: `aria-labelledby` pointing to dialog title, focus trapped within while open
- DropdownMenu items with destructive actions: `className="text-destructive"` (Radix handles `role="menuitem"`)
- Status badges: include `aria-label` with full status text ("Concluído", "Agendado", etc.)
- Loading buttons: `aria-busy="true"` + `aria-label="Carregando..."` during submission
- Wizard step indicator: `aria-label="Passo {N} de 4"` on each dot
- Touch targets: minimum 44px height on ALL interactive elements (rows, buttons, select triggers, tab items)
- Color contrast: all text/background combinations maintain WCAG AA 4.5:1 minimum
- Empty state CTAs have descriptive `aria-label` (not just "Adicionar")
- Combobox: `aria-expanded`, `aria-controls`, `aria-activedescendant` via Radix Command primitive
