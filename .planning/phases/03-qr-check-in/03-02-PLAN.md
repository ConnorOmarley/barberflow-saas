Exported function `generateQrToken(appointmentId: string)`:
- Return type discriminated union: `Promise<{ url: string } | { error: string }>`
- Auth: usar padrão exato de appointments.ts — `createClient()` + `supabase.auth.getClaims()` + verificar barbershop_id do JWT
- Após auth, usar `createAdminClient()` para buscar o appointment:
  - SELECT id, start_time, status, barbershop_id FROM appointments WHERE id = appointmentId AND barbershop_id = barbershop_id (belt-and-suspenders)
  - Se not found ou status === 'CANCELLED': return { error: 'Agendamento não encontrado ou cancelado' }
  - Se status !== 'CONFIRMED': return { error: 'QR disponível apenas para agendamentos confirmados' }
- Gerar token HMAC conforme RESEARCH.md:
  - issuedAt = Math.floor(Date.now() / 1000)
  - startUnix = Math.floor(new Date(appointment.start_time).getTime() / 1000)
  - payload = `${appointmentId}|${issuedAt}|${startUnix}`
  - sig = crypto.createHmac('sha256', process.env.QR_HMAC_SECRET!).update(payload).digest('hex')
  - token = `${Buffer.from(payload).toString('base64url')}.${sig}`
- Construir URL: `${process.env.NEXT_PUBLIC_APP_URL}/qr/check-in?token=${encodeURIComponent(token)}`
- Return { url }
- Wrap tudo em try/catch com `return { error: err instanceof Error ? err.message : 'Erro inesperado' }`

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Server Action → cliente browser | generateQrToken retorna apenas a URL; nunca o secret |
| Dashboard (autenticado) → página pública /qr/[appointmentId] | appointmentId é semi-público (sem dados sensíveis de cliente) |
| QR URL com token → /qr/check-in | Token HMAC protege a URL; single-use enforcement em 03-03 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04 | Information Disclosure | generateQrToken expõe URL com token HMAC | accept | Token é single-use (03-03); vaza apenas o appointmentId + timestamps; sem PII do cliente |
| T-03-05 | Spoofing | Alguém adivinhar appointmentId e acessar /qr/[appointmentId] | accept | Página pública não exibe PII; não gera token (token gerado só pelo owner autenticado); UUID v4 tem 122 bits de entropia |
| T-03-06 | Tampering | QR_HMAC_SECRET não definido em .env.local | mitigate | process.env.QR_HMAC_SECRET! — processo crasha com erro claro se undefined (fail-loud) |
| T-03-07 | Elevation of Privilege | 'use client' component importando createAdminClient | mitigate | AppointmentQRCode NÃO importa admin.ts; apenas recebe checkInUrl como prop |
| T-03-SC | Tampering | npm install react-qr-code | accept | Pacote auditado em RESEARCH.md — [OK], 6 anos de histórico, última publicação 2026-04-29 |
