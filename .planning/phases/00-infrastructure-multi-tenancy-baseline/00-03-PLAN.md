  </what-built>

  <how-to-verify>
    Complete these steps in order:

    1. Open Supabase Dashboard → navigate to your barberflow-saas project.

    2. In the left sidebar, go to: Authentication → Hooks.

    3. Find the "Custom Access Token" hook section.

    4. Click "Add new hook" (or "Enable" if it shows as disabled).

    5. Configure the hook:
       - Hook type: Postgres function
       - Schema: public
       - Function: custom_access_token_hook
       Click "Save" (or "Confirm").

    6. Verify the hook is now listed as active under "Custom Access Token" with function "public.custom_access_token_hook".

    After this step, every JWT issued by Supabase Auth will call custom_access_token_hook, which injects barbershop_id and role into app_metadata. Without this registration, all auth guards relying on JWT claims will fail.
  </how-to-verify>
