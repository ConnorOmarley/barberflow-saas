<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Recovery/invite link → session | token_hash in URL must be exchanged before updateUser() is called |
| Password input → Supabase | Passwords must not be logged or stored client-side |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-00-17 | Elevation of Privilege | updateUser() without active session | mitigate | useEffect checks getClaims() on page load; form hidden if no valid session |
| T-00-18 | Elevation of Privilege | Invite token reuse | mitigate | verifyOtp() in /auth/confirm is single-use; Supabase invalidates after first use |
| T-00-19 | Tampering | Password confirmation bypass | mitigate | Zod .refine() validates client-side; Supabase min password length enforced server-side |
| T-00-SC | Tampering | npm/pip/cargo installs | accept | No new packages; all dependencies from Plan 01 |
</threat_model>
