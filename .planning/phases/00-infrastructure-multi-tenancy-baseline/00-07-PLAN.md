## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → Server Component | Auth checks in Server Component layouts cannot be bypassed by client-side manipulation |
| Server Action signOut | Must run server-side only; client cannot fake signOut response |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-00-20 | Elevation of Privilege | Owner accessing /agenda | mitigate | Barber layout redirects role=owner to /dashboard; double layer with middleware |
| T-00-21 | Elevation of Privilege | Unauthenticated access to dashboard shells | mitigate | Both layouts call getClaims() server-side — second guard after middleware; defense in depth |
| T-00-22 | Spoofing | Signout not completing session cleanup | mitigate | Server Action calls supabase.auth.signOut() which clears server-side session cookie |
| T-00-SC | Tampering | npm/pip/cargo installs | accept | No new packages; all dependencies from Plan 01 |
</threat_model>
